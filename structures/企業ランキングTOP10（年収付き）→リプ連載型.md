# 企業ランキングTOP10（年収付き）→リプ連載型

- 構成（種別）: 本文 → リプ1 → リプ2 → リプ3 → リプ4

## 概要
【〇〇なら知らないと損する企業TOP10】の見出しで、10位から1位まで「N位：社名　約〇〇万円」＋短い解説を並べる。本文で10〜8位、リプ1で7〜5位、リプ2で4〜2位、リプ3で1位だけを厚めに書き、リプ4で「一番もったいないのは〇〇」から、辞めるかどうかより先に選択肢を知ろう、という締めにする。

## ルール
- 本文: 1行目に【〇〇なら知らないと損する企業TOP10】などの見出し（フック）→ 10位・9位・8位。
- 各順位: 「N位：社名　約〇〇万円」→ 何をしている会社か（事業の広さ・よく知られた特徴）を1〜2行 → 「〇〇な人ほど見る」「〇〇と決めつけない」などの行動を促す一言。
- リプ1: 7位・6位・5位。リプ2: 4位・3位・2位。
- リプ3: 1位だけ。「真っ先に確認してほしい」など一段強い言い方で、ほかより行数を多くする。
- リプ4: 「〇〇で一番もったいないのは、〜」で始め、転職する必要はないが選択肢は知っておく、という締め。
- 年収・採用条件・求人の数字は、公式・有価証券報告書などで確認できたものだけ書く。確認できないものは「約【　】万円」の空欄にする。
- 社名と事業の説明は、よく知られた事実だけにする（確信がない企業は入れない）。年収や募集状況は時期で変わる旨を一言添える。

## お手本

### 本文
```
【第二新卒なら知らないと損する企業TOP10】
10位：SHIFT　約500万円
IT未経験・第二新卒向けの採用を公式で実施。
前職アパレル、営業事務などから転職した社員例も公開されています。
IT業界に行きたいのに、
経験がないから諦めている人ほど見る。
9位：オープンハウス　約620万円
営業職では経験不問の募集あり。
公式では営業・不動産業界ともに未経験OK。現在の求人には1年目平均年収617万円という例もあります。
年齢が若いうちに成果で収入を上げたい人は、一度条件を見る。
8位：レバレジーズ　約650万円
人材だけではなく、
IT、医療など複数領域に事業を展開。
未経験歓迎のマーケティング求人では500〜800万円の募集例もあります。
「若手だから営業しかない」で求人を探す必要はありません。
```

### リプ2
```
4位：楽天グループ　約820万円
ECだけでなく、カード、銀行、証券、モバイル、広告など事業がかなり多い。
だから、「楽天に転職する」ではなく、
「楽天のどの事業の、どの仕事に転職するか」まで見る。一社の中でも選択肢がかなり違います。
3位：リクルート　約1,150万円
第二新卒・若手転職で候補に入れる人も多い会社。
人材だけではなく、
住宅、美容、飲食など幅広い領域でサービスを展開。
会社名だけ見て「人材営業」と決めつけない。
2位：日本IBM　約900万円
「外資ITだからエンジニア経験が必要」と思って最初から検索しない人が多い。
でもIBMはコンサルティングからテクノロジーまで事業領域が広い。
第二新卒なら、会社のイメージではなく、募集枠の応募条件を見る。
```

### リプ3
```
1位：アクセンチュア　約660万円
第二新卒なら真っ先に確認してほしい。
公式採用ページに、
「未経験からコンサルタント・エンジニアへキャリアを築くチャンス」と明記されています。
対象は社会人経験4か月以上5年未満で、ビジネスコンサルタント等の標準年収は663万円。
「コンサル経験がないから」
という理由だけで候補から外す必要はありません。
```

### リプ4
```
第二新卒の転職で一番もったいないのは、
「今の会社で3年働いてから考えよう」と、求人すら調べないこと。
転職する必要はありません。
でも、
今どんな企業に応募できるのか
今の年収はいくらなのか
どんな経験が評価されるのか
これは知っておく。
第二新卒枠は、
ずっと使えるわけではありません。
実際アクセンチュアの第二新卒採用にも社会人経験期間の条件があります。
辞めるかどうかより先に、自分の選択肢を知ってください。
```
