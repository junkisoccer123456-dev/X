# 面接官の質問→残念な回答→内定回答型

- 構成（種別）: 本文 → リプ1 → リプ2

## 概要
本文で面接官の質問を1つ出し、よくある「残念な回答」を3つ並べて「内定する回答と考え方↓」でリプに引っ張る。リプ1で「内定する転職者」の回答を3パターン（①②＋条件付きの1つ）見せ、「3つに共通してるポイントは、」でつなぐ。リプ2で共通ポイント5つと、面接官がその質問をする本当の理由、最後に「保存して、面接前に〜してみてください」で締める。

## ルール
- 絵文字は使わない（アカウントのルールを優先）。お手本の絵文字ラベルは【面接官】【残念な回答】【内定する回答】などの見出しに置き換える。
- 本文: 【面接官】→「質問」→【残念な回答】→「」付きのNG回答×3 →「内定する回答と考え方↓」。
- リプ1: 【内定する転職者①】「回答」、【内定する転職者②】「回答」、【内定する転職者（〇〇な場合）】「回答」→「3つに共通してるポイントは、」。
- リプ2: 「共通してるポイントは、」＋「・」の箇条書き5つ → 面接官がこの質問をする本当の理由（〜したいからではなく、〜したいから）→ NG回答が響かない理由と、信頼される人の条件 →「保存して、面接前に〜を言葉にしてみてください。」
- 方言はまねず、アカウントの口調で書く。

## お手本

### 本文
```
👨‍💼面接官
「内定を出したら入社してくれますか?」
🙅残念な回答
「絶対に辞退しません」
「本当に御社が第一志望なので」
「他は受けていないので大丈夫です」
🙆内定する回答と考え方↓
```

### リプ1
```
🙆内定する転職者①
「他社も並行して受けていますが、どこも同じ軸で選んでいます。その中でも御社は◯◯の点で最も条件が合っていて、内定をいただければ迷わず決めます」
🙆内定する転職者②
「口約束ではなく、条件面で確認したい点はすでに整理しています。それが満たされれば、辞退する理由は自分の中にありません」
🙆内定する転職者（覚悟で押す場合）
「正直、他社の選考も進んでいます。ただ、御社を本命にした理由は面接を通じて固まってきていて、その理由は変わらないと思っています」
3つに共通してるポイントが、
```

### リプ2
```
共通してるポイントは、
・「絶対に辞退しません」の宣言で終わらせない
・他社を受けてる事実を隠さない
・"軸"があることを示す
・条件面の懸念を先に潰しておく
・理由つきで「本命」と言い切る
面接官がこの質問をするのは、忠誠心を試したいからやない。内定を出した後の離脱リスクを、事前に減らしたいからや。
理由のない「絶対辞退しません」は、全員が言う。だから響かん。逆に、他社を受けてる事実を正直に認めた上で、"軸"と"理由"をセットで語れる人は、むしろ信頼される。
保存して、面接前に自分の"軸"と、御社が本命な理由を言葉にしてみてください。
```
