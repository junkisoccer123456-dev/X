# 言語化リスト→効果提示型

- 構成（種別）: 本文

## 概要
1投稿完結。「面接官を10年やってますが、」のフックから「〇〇の方が〜しておくと一気に楽になること5選」を示し、「・「問い」 → 効果」の形で5つ並べる。最後に「〜で落ちてる方が本当に多いです、、、」系の本音で締める。

## ルール
- 1〜2行目: 「面接官を10年やってますが、」＋改行＋「〇〇の方が『〜』5選」。
- 各項目: 「・「自分に問う形の項目」 → 言語化するとどう伝わるか」。5項目。
- 締め: 1文。「、、、」で余韻を残してもよい。
- 数値は創作しない。

## お手本

### 本文
```
面接官を10年やってますが、
エンジニアの方が「面接前に言語化しておくと一気に楽になること」5選

・「担当したのはどの工程か」 → 経験の粒度が正しく伝わる
・「なぜその技術を選んだか」 → 作業の話が判断の話に変わる
・「詰まったときの調べ方」 → 実務の再現性が見える
・「チーム何人と、どう関わったか」 → 独学との差が出る
・「今いちばん伸ばしたい領域」 → 志望動機と地続きになる

実力の差というより、言語化の差で落ちてる方が本当に多いです、、、
```
