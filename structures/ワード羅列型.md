# ワード羅列型

- 構成（種別）: 本文

## 概要
1投稿完結。1行目に「〇〇で日常的に使われるワード」のような見出しを置き、その場面で実際に耳にする言葉を「・「」」で15個前後並べるだけの短い投稿。説明は付けず、読者が「あるある」「うちもそう」と自分の職場に当てはめて反応したくなる形にする。

## ルール
- 1行目: 「〇〇で日常的に使われるワード」など、場面と対象がひと目で分かる見出し（これがフック）。
- 2行目は空行。3行目以降に「・「言葉」」を15個前後。短い言葉から長い言葉の順に並べると読みやすい。
- 言葉には説明や注釈を付けない。締めの一文も原則なし（付けるなら1行まで）。
- 特定の会社・個人を名指ししない。発信者の実体験として断定しない（「よく使われる言葉」として並べる）。

```
ブラック企業で日常的に使われるワード

・「給料泥棒」
・「もう帰るの？」
・「自分で考えて」
・「やる気ある？」
・「前に教えたよね」
・「根性が足りない」

・「みんな頑張っている」
・「家族だと思っている」
・「君の成長のためだから」
・「怒られているうちが華」
・「昨日は〇時まで残ったよ」
・「休みは取れる時に取ればいい」
・「パワハラはされる方に問題がある」
・「俺が若い頃はもっと厳しく指導された」
```
