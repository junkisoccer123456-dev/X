# 謳い文句→実態の暴露→構造の結論型

- 構成（種別）: 本文

## 概要
1投稿完結の中〜長文。発信者の経歴で「内側にいた人間が構造の裏側を話す」と宣言 → 業界・会社がよく使う「謳い文句」を4つ並べ、それぞれ「→」で実態を1〜2行で暴く → 実態がそうなる構造上の理由を2〜3行で説明 → 「〇〇のつもりが、いつのまにか〇〇」という読者のすり替わりを指摘し、業界の現状への一言で締める。

## ルール
- 1行目: 経歴を使ったフック（「〇〇で〇年間、〇〇の現場にいた私が、構造の裏側を話します」など）。
- 謳い文句は「」で囲み、実際によく見る言い回しにする。4つ前後。
- 各実態は「→」で始め、1〜2行。誰かの悪意ではなく、数・時間・お金の構造で説明できる実態にする。
- 構造の説明: なぜそうなるか（コスト・評価指標・人員など）を2〜3行。
- 締め: 「〇〇を探していたはずが、いつのまにか〇〇を探している」型のすり替わり → 「この構造に気づかないまま〇〇する人が多い」で終える。
- 割合・件数などの数字は、accounts/ にある事実か確認できたものだけ。
- imai の口調では「ぶっちゃけ」は使わない（お手本の1行目は「構造の裏側をお話しします」などに言い換える）。

## お手本

### 本文
```
マイナビで12年間、人材紹介の現場にいた私が、構造の裏側をぶっちゃけます

「専任アドバイザーが親身にサポートします」
→ その担当は、月に何十件もの面談をさばいている。じっくり話せるのは、最初の一回だけ。

「あなたに合う求人を厳選してご紹介」
→ 実際に届くのは、DBから抽出された求人が大量に並んだメール。

「キャリアを一緒に考えましょう」
→ 気づけば、あなたに合う会社ではなく「決まりやすい会社」をすすめられている。

「一人ひとりに寄り添います」
→ 登録者数に対して、アドバイザーの数が足りていない。持ち数が多ければ、寄り添う時間はどうしても削られる。

大手は人件費以外に広告費や家賃という大きなコストを抱えている。だから「多くの人を、早く決める」ことが、構造上どうしても優先される。
「自分に合う会社」を探していたはずが、いつのまにか「エージェントが決めやすい会社」を探している。
この構造に気づかないまま、転職を終える人が、あまりに多いのがいまの人材業界です。
```
