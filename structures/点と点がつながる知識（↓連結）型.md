# 点と点がつながる知識（↓連結）型

- 構成（種別）: 本文

## 概要
1投稿完結の短文。「エンジニアが覚えると『点と点がつながる』知識5選」→ 5つの技術を「↓」でつなぐ → 最初はバラバラに見えるが、つながりで見ると理解できる、という3行で締める。

## ルール
- 1行目: エンジニアが覚えると「点と点がつながる」〇〇5選
- 5項目を1行ずつ、間に「↓」の行を挟む。前の項目が次の項目の前提になる順番にする（技術的に筋が通る順序）。
- 締め3行: 最初は別々に見える → 〇〇を見ながら覚えるとつながる → 「単体より『つながり』で覚えるのがおすすめ」系。
- 発信者（hirai）はエンジニアではないので、「僕が勉強したとき」などの一人称の学習体験は書かない。

## お手本

### 本文
```
エンジニアが覚えると「点と点がつながる」知識5選


HTTP
↓
API
↓
認証・認可
↓
DB
↓
クラウド
最初は全部別の技術に見える。
でもシステム構成図を見ながら勉強すると、急に理解できるようになった。
技術は単体より「つながり」で覚えるのがおすすめ。
```
