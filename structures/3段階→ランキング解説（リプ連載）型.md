# 3段階→ランキング解説（リプ連載）型

- 構成（種別）: 本文 → リプ1 → リプ2 → リプ3 → リプ4

## 概要
本文で「〇〇したい人は、〇〇より先に〇〇を選んでください」と言い切り、🥉やめとけ／🥈無難の2段階を見せて、🥇いちばん確実な方法だけ伏せる。リプ1で🥇を公開して根拠を3つ並べ、「その他も含めて解説します↓」。リプ2〜3で5位→1位のランキング（各順位にラベルと「・」2項目）を2回に分けて出し、リプ4で「〇〇は、〇〇ではなく〇〇で決まります」と判断基準を言い切って締める。

## ルール
- 絵文字は使わない（アカウントのルールを優先）。🥉🥈🥇は【やめとけ】【無難】【いちばん確実】などの見出しに置き換える。
- 本文: 1行目で「〇〇な人は、〇〇より先に〇〇を選んでください」→【やめとけ】・1項目 →【無難】・1項目 →「いちばん確実なのは↓」。
- リプ1: 【いちばん確実な方法】「一言」→「・」根拠3つ →「その他も含めて解説します↓」。
- リプ2: 「〇〇ランキング」の見出し → 5位〜3位（「N位：ラベル」＋「・」2項目）→「ここからが重要です↓」。
- リプ3: 2位・1位（同じ形）→「解説↓」。
- リプ4: 判断基準を1文で言い切り、確認すべき具体的なポイント（求人票のどこを見るか等）と「口頭の〇〇は根拠にならない」系の一言で締める。
- 数値の統計は創作しない。

## お手本

### 本文
```
転勤したくない人は、会社より先に働き方を選んでください

🥉やめとけ
・総合職で入って後から交渉する

🥈無難
・地域限定職を選ぶ

🥇いちばん確実なのは↓
```

### リプ1
```
🥇いちばん確実な方法
「転勤の概念がない職種を選ぶ」

・勤務地が事業所に固定される
・異動しても同一エリア
・求人票に明記されている

その他も含めて解説します↓
```

### リプ2
```
転勤が少ない働き方ランキング

5位：条件つき
・地域限定の総合職
・工場勤務

4位：比較的安定
・経理、人事などの管理部門
・社内SE

3位：ほぼ動かない
・エンジニア
・インサイドセールス

ここからが重要です↓
```

### リプ3
```
2位：勤務地が選べる
・エリア限定職での採用
・地場企業の本社職

1位：構造的に動かない
・事業所が1カ所の会社
・リモート前提の職種

解説↓
```

### リプ4
```
転勤の有無は、会社ではなくコース区分で決まります。

同じ会社でも、総合職と地域限定職ではまったく違う。求人票の職種区分と、異動範囲の記載を必ず見てください。口頭の「基本ありません」は、根拠にならないので。
```
