# キャリアアップ事例（▶）型

- 構成（種別）: 本文 → リプ1

## 概要
「〇〇でキャリアアップした事例」の見出しで、【現職】▶【転職先】の組み合わせを2列で並べる。本文で4〜5行出し、最後の行は転職先を空けてリプに引っ張る。リプ1で残りの組み合わせを7行ほど並べる。

## ルール
- 1行目: 「〇〇の転職でキャリアアップした事例」などの見出し。
- 2行目: 【現職】と【転職先】の列見出し。
- 各行: 「・現職のカテゴリ ▶ 転職先のカテゴリ」。全角スペースで▶の位置をそろえる。
- 本文の最後の行は「▶」で止めて、リプ1の1行目でその続きから書く。
- 特定の人物の事例として創作しない。会社名ではなく、職種・企業カテゴリの組み合わせ（よくあるルート）として書く。

## お手本

### 本文
```
20代中盤の転職でキャリアアップした事例

【新卒】　　　　　　【転職先】
・メガバンク 　　▶ 外資系投資銀行
・大手証券 　　　▶ 外資系投資銀行
・信託銀行 　　　▶ 大手デベ
・政府系金融 　　▶ 総合商社
・総合コンサル 　▶
```
