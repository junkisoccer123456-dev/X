# 市場の現実→今やっておくべきこと①〜⑦型

- 構成（種別）: 本文

## 概要
1投稿完結。1行目で、読者の年代・立場にとって耳の痛い採用市場の現実を言い切る（「〇〇を正社員で採りたい求人は、正直ほとんどありません」など）。2〜3行目で「それでも〇〇な人はいる。分かれ目は〇〇したかどうか」と希望と分岐点を示す。「〇〇が今やっておくべきこと」の見出しのあと、①〜⑦を1行ずつ並べ（現実→でも道はある→具体的な行動→長期の視点→注意点→背中を押す一言、の流れ）、最後に1行で行動を促して締める。

## ルール
- 1行目: 市場の現実を短く言い切るフック。
- 2〜3行目: 「それでも〜」で希望を示し、「分かれ目は〜」で分岐点を1文で。
- 見出し: 「〇〇が今やっておくべきこと」。
- ①〜⑦: 各1〜2文。前半で現実（どんな人に声がかかるか）、中盤で具体的な行動、後半で長期の視点と注意点。
- 締め: 1行で行動を促す（「〇〇の準備は、〇〇のうちに。」など）。
- 発信者の年齢・知人のエピソードなど、accounts に書いていない事実は使わない。統計のような数字は作らない。

## お手本

### 本文
```
50代を正社員で採りたい、という求人は、正直ほとんどありません。
私も今50代です。それでも、定年後も稼ぎ続ける人はいます。分かれ目は、会社員のうちに準備したかどうかです。

50代が今やっておくべきこと
①50代で声がかかるのは、代表取締役やCXOで結果を出した人が中心
②でも仕事がないわけではない。大手広告代理店を60歳で退職した先輩は、取締役ではなかったが、今は複数の会社と顧問契約
③ベンチャーでも50代の正社員枠は多くない。業務委託なら頼む会社はある
④やるべきは、フリーランス・業務委託・起業の準備
⑤80歳、90歳まで生きる時代。50代はまだ20年働く可能性がある
⑥副業は起業と同じ。安売りしたら意味がない
⑦起業は、もう特別に優秀な人だけのものではない

第2・第3の人生の準備は、会社員のうちに。
```

※ユーザーの指示により、imai ではこの構文を20代向けの内容に置き換えて使う。
