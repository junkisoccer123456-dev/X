# 企業リスト→共通点＋実体験型

- 構成（種別）: 本文
- 実績: imai で伸びたポスト

## 概要
1投稿完結の長文。見出しなしで企業名を「・」で8〜9社並べ、「〇〇な20代へおすすめ企業。」と対象者を示す。後半の1段落で、これらの会社の共通点 → 採用側がそれを重視する理由 → 発信者自身の経歴での実体験 → 具体的なエピソード → 今の気づき、の順に語る。

## ルール
- 冒頭: 「・社名」を8〜9社。見出しは付けない。社名は、後で述べる共通点に当てはまる、よく知られた企業だけにする。
- 2段落目: 「〇〇だが、〇〇と思っている20代へおすすめ企業。」の1文。
- 3段落目（1段落で続けて書く）: 「これらの会社に共通するのは、〇〇より〇〇を見ていることです。」→ 理由（〜は数か月で埋まるが、〜は数年かかる。だから採用側は後者を優先します）→「私は〇〇から〇〇に移りました。」など accounts のナレッジにある実体験 → 具体的なエピソード（当時の疑問と今の気づき）。
- 実体験・数字は accounts のナレッジにあるものだけを使う。
- 募集状況は変わる旨を最後に一言添える。

## お手本

### 本文
```
・キーエンス
・リクルート
・パーソルキャリア
・ベイカレント・コンサルティング
・アビームコンサルティング
・エス・エム・エス
・SHIFT
・オープンハウスグループ
・ラクスル

今の業界から出たいが、経験が通用しないと思っている20代へおすすめ企業。

これらの会社に共通するのは、入社時点の業界知識より、入社後の立ち上がり速度を見ていることです。業界知識は数か月で埋まりますが、目標を自分で立てて検証し直す習慣は数年かけないと身につかない。だから採用側は後者を優先します。私はキーエンスからマイナビに移りました。製造業の営業から、人材紹介です。業界も商材も全く違いました。それでも12年やれたのは、事前準備をして仮説を立て、実際との差を振り返るという型が、そのまま使えたからです。キーエンスには外出報告書という文化がありました。月に60件ほど、商談前に仮説を書き、終わったら仮説とのズレを検証する。当時は全件やる必要があるのかと疑問でした。今では、あれが業界を越える力を付けてくれたんだと思っています。
```
