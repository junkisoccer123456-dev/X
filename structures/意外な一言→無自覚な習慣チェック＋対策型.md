# 意外な一言→無自覚な習慣チェック＋対策型

- 構成（種別）: 本文 → リプ1 → リプ2

## 概要
本文で「意外な答え」を引き出す場面を書き、答えの直前（『 の直後）で切って続きを読ませる。リプ1で答え（「〇〇な人は、普段から無自覚に〇〇な習慣を続けているから〇〇なんです」）を明かし、腑に落ちた一言 → これから習慣と対策を解説する前置き → 1つ目の習慣（□見出し＋説明＋対策）→「↓↓↓↓」でリプ2へ。リプ2で残りの習慣を4つ前後（各：□見出し＋説明＋対策）並べ、「このように〜」で締める。

## ルール
- 本文: 1行目は強いフック（「二度と忘れるか。」「一生忘れない。」など短い断言）。次に「意外な答え」につながる問いを書き、答えの『 で終える。
- 本文の場面・人物は、アカウントの経歴にある事実で書けるものだけにする。知り合い・友人・専門家との会話など、accounts/ にない出来事は作らない（hirai なら「面接官10年で気づいたこと」「ブラックもホワイトも経験して分かったこと」など、本人の立場から言える観察にする）。
- リプ1: 『答え』→ 驚き・納得の一言 →「〇〇な人は、普段から無自覚に〇〇な習慣を続けているから〇〇なんです」→「該当する項目がないか確認してみてください」→ 1つ目の習慣 → 「↓↓↓↓」。
- 各習慣: 「□習慣名」→ なぜそれが悪いのか（2〜3行）→「対策：」で今日からできる具体的な行動（数字は手順・目安として書けるものだけ）。
- リプ2: 習慣を4つ前後 →「このように、〇〇は〇〇の一般常識と大きく異なる点が多いです」など、気づきで締める。
- 習慣は合計5つ前後。お手本の「☑︎」は絵文字扱いになりうるので「□」に置き換える。
- 根拠のない割合（「9割の人は」など）、研究・統計の引用は、出典を確認できたものだけ。プロフィール特典などのCTAはアカウントのCTA設定がなければ入れない。
