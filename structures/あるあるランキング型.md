# あるあるランキング型

- 構成（種別）: 本文

## 概要
1投稿完結の短文。「エンジニアの『〇〇』ランキング」→ 5位から1位まで → 1位に共感とユーモアのある一言を添えて「笑」で締める。

## ルール
- 1行目: エンジニアの「〇〇」ランキング
- 5位〜1位: 「N位：短い一言」。下位ほど軽く、1位は一番共感を呼ぶもの。
- 締め2〜3行: 1位へのツッコミや心の声。最後に「笑」を付けてもよい。
- 現場のあるあるとして自然なものにする。

## お手本

### 本文
```
エンジニアの「調査が沼るパターン」ランキング
5位：エラー文が曖昧
4位：再現したりしなかったり
3位：ログが足りない
2位：本番でしか起きない
1位：直ったけど理由が分からない
最後が一番モヤモヤする。
「直ったからヨシ！」にしたい気持ちと、
「いや原因なんだったんだ…」が戦う。笑
```
