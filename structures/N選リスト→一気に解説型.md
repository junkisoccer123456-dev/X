# N選リスト→一気に解説型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「【厳選】〇〇N選」の見出しと、読者の迷いに寄り添う一文のあと、番号付きでN個を名前だけ一覧にする。リプ1で「それではここからN個を一気に解説していきます」と前置きし、1つずつ番号つきで解説する長文。最後に「インプットしたら次は行動」系の一言で締める。

## ルール
- 本文: 「【厳選】〇〇N選をまとめました。」＋「〇〇で迷っている人も、最後まで読めば〜」→ 番号つきの一覧（名前だけ）→「ブックマークして読んでください」系の一言。
- リプ1: 「それではここからN個を一気に解説していきます」→「N. 名前」＋2〜3行の解説 ×N → 締め。
- 企業を紹介する場合は、よく知られた事業内容だけを書き、採用状況・年収・制度などの数字や断定は書かない。最後に募集状況は変わるので最新の求人で確認、と添える。
- 「いかがでしたか」などのテンプレ表現、外部アカウントや教材への誘導は入れない。
- Nは10〜15程度でよい（お手本は33）。

## お手本

### 本文
```
【厳選】これさえ覚えておけばもう怖くない！よく使う『前置詞の用法33選』をまとめました。「どの前置詞を使えばいいか迷ってしまう…」って人も、本ポストを最後まで読めば完璧です↓

1. On
2. Off
3. in
（中略）
33. before

★このポストさえ読めば、前置詞はもう怖くない！必ず【ブックマーク】して読んでください！
```

### リプ1（抜粋）
```
それではここから33個の前置詞を一気に解説していくので、最後までついてきてください！

1. on

on は「〜の上に」ではなく、くっついているイメージです。There is a mosquito on the ceiling. （天井に蚊がいる）のように、上に乗ってないときも使えます。

2. off

off は完全に離れていて、くっついていないイメージです。on と真逆です。
（中略）
インプットしたらアウトプット。僕の例文を参考に、自分で文章を作って練習してみましょう！
```

※ユーザーの指示により、hirai ではこの構文を「SESから脱却したいエンジニア向けの企業紹介」に置き換えて使う。
