# 本音提起→リプ連載解説型

- 構成（種別）: 本文 → リプ1 → リプ2 → リプ3 → リプ4

## 概要
本文で世間の思い込みに対する本音を提起し、リプ4本で「結論→前提→聞き方→確認手順」の順に連載解説する。

## ルール
- {'本文': '思い込みへの指摘（「〜の、けっこう危ないです」等）→ 理由を2〜3文 → 採用側にいる立場を示し「確認方法をまとめます」で締める。'}
- {'リプ1': '「先に結論です。」＋「・」3項目。最後は「改めて理由を...」か「改めて解説を...」。'}
- {'リプ2': '「前提として、〜」＋「・」4項目程度で構造を説明し、1〜2文で意味づけ。'}
- {'リプ3': '面接で聞く3つの質問を「・「〇〇」（分かること）」の形式で。'}
- {'リプ4': '「受ける前の確認は、この順で。」＋「・」3項目 → 対比の一言まとめ → 「保存して、次の面接で使ってください。」で締める。'}

## お手本

### 本文
```
「裁量があります」という説明、そのまま受け取ると危ないです。

裁量には2種類あって、決められる裁量と、任される裁量があります。後者は、要するに丸投げなんですよね。

面接で見分ける方法をまとめます
```

### リプ1
```
先に結論です。

・何を自分で決められるのかを具体で聞く
・決裁の範囲を聞く
・相談できる相手がいるかを聞く

改めて解説を...
```

### リプ2
```
前提として、裁量という言葉はこう使われます。

・技術や手法を自分で選べる（決められる裁量）
・目標の立て方を自分で決められる（決められる裁量）
・やり方は任せるので結果を出して（任される裁量）
・前例がないので自分で考えて（丸投げ）

下2つを裁量と呼んでいる会社は、実際には支援がありません。
```

### リプ3
```
面接で聞くならこの3つ。

・「このポジションで、自分で決められる範囲はどこまでですか」
・「判断に迷ったとき、誰に相談しますか」
・「前任の方はどこまで決めていましたか」

前任者の話が具体的に出てくる会社は、役割が整理されています。
```

### リプ4
```
受ける前の確認は、この順で。

・求人票の「業務内容」に判断の記述があるか見る
・チーム構成と人数を確認する
・面接で上の3つを聞く

裁量が欲しい人ほど、相談相手がいるかを確認してください。丸投げは裁量ではないかと。

保存して、次の面接で使ってください。
```
