# 経験N選→一言解説型

- 構成（種別）: 本文

## 概要
1投稿完結。「〇〇で武器になる経験5選」のタイトルの後、項目と「→ 一言解説」を5セット並べ、最後に面接官の視点で一言締める。

## ルール
- 1行目: 「〇〇（状況）で武器になる経験5選」の形のタイトル。
- 各項目: 1行目に経験（〜した経験）、2行目に「→ 」で始まる一言解説（なぜ評価されるか）。項目の間は空行。
- 締め: 「面接官やってると、〇〇より『〇〇』を聞きたくなります」系の1〜2文。
- 通過率などの数値は創作しない。

## お手本

### 本文
```
SESから抜けるときに武器になる経験5選

要件定義や設計の会議に同席した経験
→ 上流に触れた人は書類の通過率が変わります

自社ではなく客先の課題を提案した経験
→ 言われた作業をしてない証明になります

障害対応の一次切り分けをした経験
→ 判断してるかどうかが一番見られます

新人や後輩に手順を教えた経験
→ 年数が浅くても再現性の証拠になります

現場を移った回数と、その理由
→ 隠すより整理して出したほうが強いです

面接官やってると、SES出身かどうかより「その現場で何を任されたか」を聞きたくなります
```
