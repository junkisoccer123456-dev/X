# NG表現→OK表現の長文解説型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「〇〇のつもりで『NG表現』と言っちゃう人、ガチで危険。」と言い切り、本人は正しいつもりでも相手にはマイナスに伝わることを示して、正しい言い方はリプへ引っ張る。リプ1は長文で、OK表現（おすすめ度：MAX）とNG表現（おすすめ度：要注意）を例文つきで比較し、保存の呼びかけ → よくある場面 → 落とし穴（なぜ勘違いするか）→ 面接官としての見え方 → NG表現が問題にならない場面 → まとめ、の順で解説する。

## ルール
- 絵文字・★・✅は使わない（アカウントのルールを優先）。見出しは【　】、箇条書きは「・」にする。
- 本文: 1行目で「〇〇のつもりで『NG表現』と言っちゃう人、ガチで危険。」→ 本人の意図と相手の受け取り方のズレを1〜2文 →「〇〇に誤解されずに〜を届ける言い方は↓」。
- リプ1: 【9割が知らない〇〇の正体】→ OK表現（おすすめ度：MAX）の意味・使う場面・例文 → NG表現（おすすめ度：要注意）の意味・例文 → 保存の呼びかけ →「特に要注意なのが〜」の場面 →「でもここが落とし穴。」→ 面接官としての見え方（アカウントの経歴の範囲で。本人の失敗談は創作しない）→「そしてここ重要。」でNG表現が問題ない場面 →「つまり」で2行のまとめ → 締め。
- 「いかがでしたか」などのテンプレ表現、外部アカウントへの誘導は入れない。

## お手本

### 本文
```
「忘れました」と謝るつもりで"I forgot"と言っちゃう人、ガチで危険。

正直に報告して反省したつもりが、知らないうちに「無責任なヤツ」とレッテルが貼られてしまう…

ネイティブに勘違いされずに「誠実な謝罪と報告」を届けるフレーズは⇩
```

### リプ1（抜粋）
```
【9割が知らないI forgotの正体】
★It slipped my mind.
★I completely missed that
（おすすめ度：MAX）
・「申し訳ありません、うっかり失念しておりました」という、誠実にミスを認める大人の表現。
・ビジネスで何かをやり忘れた時に、相手への配慮と深い反省を示す鉄板フレーズ。

★I forgot（おすすめ度：要注意）
・「忘れちゃった！」という、日常のどうでもいい事柄に対する非常に軽い表現。

【今日この投稿を見つけたあなたはラッキーです。保存＋いいねしておいてください。】

特に要注意なのが、上司やクライアントに「あの件、どうなった？」と聞かれて自分のミスに気づいた時の "I forgot."。
（中略）
でもここが落とし穴。
（中略）
そしてここ重要。
"I forgot" が最高に「ナチュラル」に機能する場面もあります。
（中略）
つまり
✅ビジネスで失念してしまい、誠実に謝罪するなら→「It slipped my mind」
✅無意識に「忘れちゃったテヘ」と反省ゼロの言い訳になる危険があるのが→「I forgot」
```
