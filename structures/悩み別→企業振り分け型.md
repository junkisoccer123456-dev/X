# 悩み別→企業振り分け型

- 構成（種別）: 本文 → リプ

## 概要
「〇〇別」の切り口で、読者の悩み（現場のつらさ）ごとに受けるべき会社を3社ずつ振り分ける。本文は3つ目の悩みの見出しで止めてリプに引っ張る。リプで残りを出し、読者の心の声『〜』で共感させてから、面接官の視点の一言で締める。

## ルール
- 本文: 1行目に”〇〇別”のくくり → 「〇〇が受けるべき会社はこれ。」 → 【悩み】→ 社名3つ、を2セット → 3つ目の【悩み】だけ書いて「⇓」で止める。
- リプ: 3つ目の【悩み】を再掲して社名3つ → さらに2セット（計5つの悩み） → 『読者の心の声』を2つ → 「↓↓」 → 面接官視点で「〜の話。」 → 行動を促す一言。
- 社名は、その悩みの解決につながる特徴（自社開発・元請け・大手メーカー系・Web系など）で、よく知られた企業だけを挙げる。確信がない企業は入れない。
- 悩みは読者の実感がある具体的な場面にする（「スキルシートに書いた技術を触っていない」など）。

## お手本

### 本文
```
”現場のつらさ別”
SES2年目が受けるべき会社はこれ。

【常駐先が変わるたび信用を作り直している】
→サイボウズ、ラクス、Sansan

【自社の人と月に1回しか話していない】
→SmartHR、マネーフォワード、freee

【自分の担当範囲が説明できない】
⇓
```

### リプ
```
【自分の担当範囲が説明できない】
→NTTデータ、SCSK、TIS

【客先の社員のほうが自分の案件に詳しい】
→NEC、富士通、日立製作所

【スキルシートに書いた技術を触っていない】
→GMOペパボ、はてな、カヤック


『SES出身でも通る求人が探せない』
『職務経歴書に書けることが参画案件しかない』

↓↓
SESの2年目は経験年数だけ見ると足りているのに、書類で落ちます。
技術の話ではなく、書類と面接でどう見えるかの話。

職場に違和感を持ったら環境を変える選択肢も持つべきです。
```
