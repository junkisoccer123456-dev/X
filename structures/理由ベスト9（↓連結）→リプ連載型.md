# 理由ベスト9（↓連結）→リプ連載型

- 構成（種別）: 本文 → リプ1 → リプ2 → リプ3

## 概要
「〇〇が〇〇になる理由ベスト9」を、第9位から第1位まで「↓」でつなぎながらリプで連載する。冒頭に「大前提：この数字（現象）が何を意味するか」を置き、下位は構造の出発点（コスト・仕組み）、上位ほど本質的な原因にする。各リプの最後に次の順位の見出しだけ出して「続きはリプ欄に」で引っ張る。最後のリプで第1位を長めに書き、発信者の経歴で裏づけて締める。

## ルール
- 本文: 1行目「〇〇が、〇〇になる理由ベスト9」→「大前提：まず、〇〇が何を意味するか」＋「└」で始まる説明 →「↓」→ 第9位・第8位（各「第N位：見出し」＋「└」で始まる2〜3行の説明、間に「↓」）→ 第7位の見出しだけ →「続きはリプ欄に」「↓」。
- リプ1: 第7位（見出しを繰り返す）・第6位・第5位 → 第4位の見出しだけ →「続きはリプ欄に」。
- リプ2: 第4位・第3位・第2位 → 第1位の見出しだけ →「続きはリプ欄に」。
- リプ3: 第1位の見出し → 段落で長めに解説（なぜ是正されないのか、悪意ではなく仕組みの問題）→ 発信者の経歴を使った裏づけ（「私は〇〇で〇年、〜」）→ 構造の結論。
- 順位は前の順位の結果として次がつながるように並べる（因果の連鎖）。
- 誰かを責めるのではなく「構造の話」として書く。数字は accounts/ の事実か確認できたものだけ。

## お手本

### 本文
```
大手エージェントの担当者が、
月40〜50面談になる理由ベスト❾

大前提：まず、この数字が何を意味するか
└営業日が20日として、1日2件から2.5件。企業への対応、書類の添削、面接日程の調整、社内の報告業務がこれに並行します。

↓
第9位：人件費以外の固定費が大きい
└大手は広告宣伝費、オフィス賃料、システム利用料など、社員1人の給与以外にも多額のコストがかかります。この固定費を誰が回収するのかという話が、すべての出発点。

↓
第8位：社員1人が黒字になるまでの決定件数が多い
└固定費が大きいほど、1人あたりが成立させなければならない転職決定の数は増える。決定を増やすには、面談を増やすしかない。構造の話ですね。

↓
第7位：登録者数に対して、担当者の増員が追いつかない

続きはリプ欄に
↓
```

### リプ1
```
第7位：登録者数に対して、担当者の増員が追いつかない
└求職者の登録は広告投下で増やせますが、キャリアアドバイザーの採用と育成には時間がかかります。この時間差が、そのまま1人あたりの担当数に乗ります。

第6位：企業側の対応数にも同じ原理が働く
└求職者だけでなく、担当する企業の数も同様に膨らみます。両面型であればなおさら。1人の担当者が抱える情報量が、処理できる限界を超えていきます。

第5位：数をこなすと、結果が読める
└面談数を増やせば、決定率は一定の水準に収束します。経営として数字が読みやすくなる。これは合理的な判断であって、誰かの怠慢ではありません。

第4位：求人の提案がシステム側に寄る

続きはリプ欄に
```

### リプ2
```
第4位：求人の提案がシステム側に寄る
└1人に長く向き合う時間が取れなければ、条件で絞り込んだ求人を提示する形にならざるを得ない。丁寧に聞き取ったうえで求人を選ぶという工程が、時間的に成立しなくなります。（構造的な限界）

第3位：面談の型が固定化する
└同じ流れで同じ質問をすれば、時間内に必要な情報は集まります。ただしその型からはみ出す事情、たとえば転職すべきでない状況にある方を見つけることは難しくなる。

第2位：担当者の入れ替わりが起きる
└この負荷が続けば、離れる人が出ます。担当が変わればまた一から説明することになり、求職者側の体験はさらに悪くなる。この循環が、構造をさらに強めていきます。

第1位：面談の質が、誰にも計測されていない
```

### リプ3
```
第1位：面談の質が、誰にも計測されていない

エージェントの評価指標は、決定数と売上です。

面談数も追われます。ただし、その面談が求職者にとって良かったかどうかを測る指標は、社内のどこにも存在しません。だから面談数だけが増え続けます。数は数えられるが、質は数えられない。数えられないものは、経営判断の材料にならない。ここまでのポイントが是正されないのは、悪意があるからではなく、是正すべき状態を検知する仕組みがないからです。

私はマイナビで12年、中途紹介部門を1人から100名規模まで立ち上げました。組織をつくる側にいたので分かりますが、質を測る指標を置こうとすると、必ず「それは何で測るのか」で止まります。決定数は誰が見ても同じ数字になりますが、面談の質は人によって答えが変わります。だからこそここは計測されず、分かりやすく売り上げを追う組織が出来上がるという構造です。
```
