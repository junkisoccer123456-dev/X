# 信じていい記載↔鵜呑みにしない記載（2列対比）型

- 構成（種別）: 本文

## 概要
1投稿完結。「信じていい記載（具体的・数字や固有名詞で書かれている）」と「鵜呑みにしない記載（抽象的・ぼかした言い方）」を左右2列に並べ、同じ行どうしが対になるように8〜10組見せる。読者が自分で見比べて「具体か、抽象か」の判断軸に気づく構成。

## ルール
- 1行目に、何を見比べるリストかが分かるフック（アカウントのルールで冒頭のフックが必須の場合）。
- 列見出しは【信じていい〇〇】【鵜呑みにしない〇〇】。お手本の❶❷などの記号は使わない。
- 各行: 「・左の項目」＋全角スペースで位置をそろえて「・右の項目」。同じ行の左右は同じ観点（例: 残業の書き方）の対比にする。
- 左は「◯日」「◯時間（実績）」のように、数字や固有名詞が入る形（◯は伏せ字のまま）。右は「アットホーム」「ほぼなし」のようなぼかした表現。
- 最後に1〜2行で判断軸をまとめてもよい（「具体的に書けるのは、実態があるから」など）。

## お手本

### 本文
```
❶信じていい記載　　　　　　　❷鵜呑みにしない記載
・年間休日◯日　　　　　　　・アットホームな職場
・平均残業◯時間（実績）　　・残業ほぼなし
・固定残業◯時間分　　　　　・みなし残業あり（時間なし）
・離職率◯％　　　　　　　　・風通しが良い
・有給取得率◯％　　　　　　・有給取得を推奨
・想定年収◯万〜◯万　　　　・年収応相談
・勤務地を事業所名で明記　　・勤務地は首都圏一円
・選考フローの回数　　　　　・選考は柔軟に対応
・使用技術のバージョン　　　・最新技術に触れられる
・募集背景（増員・欠員）　　・急成長中のため募集
```
