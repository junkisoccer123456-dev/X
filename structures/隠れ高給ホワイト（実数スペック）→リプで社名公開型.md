# 隠れ高給ホワイト（実数スペック）→リプで社名公開型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「【平均〇〇万円】知名度は低いのに待遇が良い隠れホワイト」のような見出しを置き、社名を伏せたまま、確認できる実数（平均年収・離職率・残業・有給・賞与・創業年・事業の広がり・成長への投資など）を「・数字の見出し」＋1〜2行の解説で5〜6項目並べる。最後に「〇〇なのに派手さはない、でも中身は一級品…その企業の名は…」で引っ張る。リプ1で「その名は…〇〇（業界）の〇〇、【社名】です。」と公開し、何をしている会社か、なぜ知名度が低いのか、イメージと実態の差を2〜3段落で書き、候補から外すのはもったいない、という一言で締める。

## ルール
- **数字はすべて公開資料で確認できたものだけ**を使い、各数字のあとに出典と年度を（2025年3月期・有価証券報告書）のように添える。確認できない項目は書かない（項目数が減ってもよい）。
- 「学歴なしでも入れる」「中途採用に積極的」「20代の実績が増えている」など、採用のしやすさや選考の実態は、確認できない限り書かない。
- 有報の平均年収は提出会社（持株会社の場合はその旨）の数字であることを踏まえ、「20代でも〜」など年代別の断定はしない。
- 最後に、数字は年度で変わる・募集状況は最新の求人で確認、の一言を入れる。
- 絵文字・ハッシュタグはアカウントのルールに従う。

### 本文
```
【平均1,137万円”学歴なしでも入れる”隠れ高給ホワイト

・平均年収1,137万円
専門商社の中でもトップクラスの水準。20代でも同世代を大きく上回る。（2025年3月期・有価証券報告書）
・自己都合離職率はわずか3.8%
一度入ったら辞めない。定着率の高さが、そのまま働きやすさの裏づけになっている。
・平均残業は月17時間ほど
商社ながら、だらだら残業とは無縁。有給取得も年13.6日と、実際にしっかり休めている。
・賞与は基本給の6〜7ヶ月分
年2回の賞与が厚く、年収の底上げに大きく効いてくる。
・1832年創業、30か国以上に広がるグローバル企業
染料から医薬品原料、電子材料、化粧品まで。あらゆる産業の「素材」を世界とつなぐ老舗。
・安定基盤×成長機会の両取り
半導体材料の回収・再生工場を新設するなど、次の時代の事業もしっかり仕込んでいる。

商社なのに派手さはない、でも中身は一級品…その企業の名は…
```

### リプ1
```
その名は…　化学系専門商社の老舗、長瀬産業（NAGASE）です。

総合商社ほど名前は知られていませんが、染料・化学品・電子材料・化粧品原料など、あらゆる産業の「素材」を世界中から調達して届けているのが長瀬産業。
BtoBで一般の目に触れないぶん、平均年収1,137万円という待遇のわりに知名度は控えめ。「商社＝激務」のイメージで敬遠している人もいますが、残業は月17時間ほど、離職率3.8%と、実態はかなり働きやすい部類という話です。
もちろん転職難易度は高めですが、近年は中途採用にも積極的で、20代・第二新卒の実績も増えています。総合商社ばかり見て専門商社を候補から外すのは、正直もったいないかなと思いますよ。
```
