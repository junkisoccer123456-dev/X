# NGフレーズ5選→裏のニュアンス→長文解説型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「知らずに使うとヤバい〇〇フレーズ5選」として、よかれと思って使うフレーズを①〜⑤で並べ（括弧で本人の意図を添える）、「実はこれ、〇〇にはこう受け取られてます⇩」でリプへ。リプ1で保存の呼びかけ →【〇〇が受け取る裏のニュアンス】①〜⑤ →「ここからが超重要な解説です。」→ 読者の思い込みを問いかけ → はっきり言い切る → 5つのうち3つを掘り下げ（なぜそう受け取られるか＋正しい言い方を「」で）→ 思い込みを捨てるよう促し、評価される本質を1文で締める。

## ルール
- 本文: 1行目「知らずに使うとヤバい〇〇フレーズ5選」→ ①〜⑤「フレーズ（意図）」→「実はこれ、〇〇にはこう受け取られてます⇩」。
- リプ1: 「〜いつでも見返せるように、今のうちに【保存】しておいてください！」→【〇〇が受け取る裏のニュアンス】①〜⑤「〜な人」→「ここからが超重要な解説です。」→「『〇〇でしょ』って思っていませんか？」→「はっきり言います。」→ 3つを「いちばん多いのが」「次に」「そして」で掘り下げ、それぞれ正しい言い方を「」で示す →「『〇〇』という思い込みは今すぐ捨ててください。」→ 評価の本質を1文。
- 正しい言い方は〇〇の穴埋めにして、読者が自分の数字や経験を入れられる形にする。
- 経歴・数字はアカウントに書いてある事実だけを使う。

## お手本

### 本文
```
知らずに使うとヤバい面接フレーズ5選

①御社の規定に従います（年収について）
②なんでもやります！（意欲を伝えたい）
③言われた通りにやっていました（素直さを伝えたい）
④特にありません（逆質問で）
⑤勉強させていただきたいです（成長意欲を伝えたい）

実はこれ、面接官にはこう受け取られてます⇩
```

### リプ1
```
面接の直前にいつでも見返せるように、今のうちに【保存】しておいてください！

【面接官が受け取る裏のニュアンス】
①「自分の相場を調べていない人」
②「何ができるか自分でも分かっていない人」
③「自分で判断した経験がない人」
④「入社後を想像していない人」
⑤「教えてもらう前提で来ている人」

ここからが超重要な解説です。
「謙虚に言えば好印象になるでしょ」って思っていませんか？

はっきり言います。面接では、謙虚さと準備不足が同じ言葉で出てきます。そして面接官は、準備不足のほうを先に読みます。

いちばん多いのが①の「御社の規定に従います」。遠慮のつもりで言う方が多いですが、こちらからすると「現年収も市場の水準も調べていない」と受け取ります。等級を決めるのは面接の評価ですが、提示を組むときに希望が分からないと、下のほうで組まれます。正しくは「現在〇〇万円です。同等の役割であれば〇〇万円を目安に考えておりますが、役割によって適正は変わると認識しています」。これだけで印象が変わります。

次に②の「なんでもやります」。意欲として言っているのは分かります。ただ、配属を考える側からすると、どこに置けばいいか分からない人になります。「特に避けたい業務はありません。ただ〇〇は経験が浅いので、最初は時間をいただきたいです」と、できる範囲とできない範囲を分けて言ってください。

そして⑤の「勉強させていただきたいです」。これは学生の言葉です。中途採用は、教える前提ではなく、立ち上がる前提で採ります。「〇ヶ月で一人で回せる状態を目指します。最初の〇ヶ月は質問の量が多くなると思います」と、期間で答えてください。

「謙虚＝好印象」という思い込みは今すぐ捨ててください。
面接で評価されるのは、低く出ることではなく、自分の現在地を正確に言えることです。
```
