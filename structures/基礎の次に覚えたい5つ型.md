# 基礎の次に覚えたい5つ型

- 構成（種別）: 本文

## 概要
1投稿完結の短文。「〇〇、その次に覚えたい5つ」→ 基礎として覚えたもの → 「その次に勉強したいのが、」→ 5項目 → 「ここから『〇〇できる』から『〇〇できる』に変わっていく。」で締める。

## ルール
- 1行目: エンジニアが最初に覚える〇〇、その次に覚えたい5つ
- 2段落目: 最初に覚えるもの（3つ程度）を並べて「〜を覚えた。」
- 「その次に勉強したいのが、」→「・」で5項目（技術的に正しい順序・粒度で）
- 締め: 「ここから『〇〇が書ける/使える』から『〇〇を考えて使える』に変わっていく。」の形。

## お手本

### 本文
```
エンジニアが最初に覚えるSQL、その次に覚えたい5つ

SELECT、INSERT、UPDATEを覚えた。

その次に勉強したいのが、

・JOIN
・GROUP BY
・INDEX
・トランザクション
・実行計画
ここから「SQLが書ける」から「DBを考えて使える」に変わっていく。
```
