# 地味だけど超重要型

- 構成（種別）: 本文

## 概要
1投稿完結の短文。「〇〇で地味だけど超重要なもの」→「・項目」と「→ 一言の役割」を5セット → 「〇〇ができるようになった『次』に覚えたいところ。」で締める。

## ルール
- 1行目: 〇〇で地味だけど超重要なもの
- 5項目: 「・項目」の次の行に「→ 役割（10〜15字）」。項目の間は空行。技術的に正確に。
- 締め1行: 基礎の「次」に覚えたい、という位置づけ。

## お手本

### 本文
```
DBで地味だけど超重要なもの

・インデックス
→ 検索を高速化

・トランザクション
→ 一連の処理をまとめて管理

・ロック
→ 同時更新による不整合を防ぐ

・バックアップ
→ 最後の砦

・実行計画
→ SQLが遅い原因を探す

SQLを書けるようになった「次」に覚えたいところ。
```
