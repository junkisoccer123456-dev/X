# 年齢別タイムライン（面接で会った人）型

- 構成（種別）: 本文 → リプ1 → リプ2

## 概要
「以前、面接でお会いした〇歳の方。能力が低かったわけではないですが....」で始め、【22歳（新卒）】から2年刻みで、仕事内容・任される範囲・年収の推移を淡々と並べる。本文は3ステップで止め、リプ1で続きの3ステップ、リプ2で現在の姿と、面接官として感じた「足りなかったもの」を書き、読者への問いかけで締める。

## ルール
- 本文: 「以前、面接でお会いした〇歳の方。能力が低かったわけではないですが....」→【年齢】＋2〜3行×3 →【次の年齢】＋「↓」。
- リプ1: 【年齢】＋2〜3行×3 →【現在の年齢】＋「↓」。
- リプ2: 【〇歳（現在）】＋現在の状況 → 面接での印象（知識やスキルは足りていた）→ 足りなかったもの（自分で決めた経験など）→「僕の肌感覚だと〜」→ 読者への問いかけ「〜はどれくらいありますか？？」。
- 実在の特定の人物の話として創作しない。リプ2の最後に「複数の面接で聞いた話をもとにした、よくある流れです」と添える。
- 年収などの数値は創作しない。「年収は【　】万円」の空欄にするか、「ほぼ横ばい」のようにぼかす。

## お手本

### 本文
```
以前、面接でお会いした32歳の方。能力が低かったわけではないですが....

【22歳（新卒）】
SES企業に入社し、金融系の保守案件へ常駐。
障害対応とデータ修正が中心。年収は320万円。

【24歳】
同じ現場で3年目。作業には完全に慣れ、誰よりも早く終わるようになる。
ただ任される範囲は変わらないまま。年収は345万円。

【26歳】
現場から継続指名を受け続ける。
居心地は良く、残業もほぼない。年収は370万円。

【28歳】
↓
```

### リプ1
```
【28歳】
5年目の現場。周りのメンバーは入れ替わるが、自分の役割は変わらない。
技術選定にも設計にも関わらない期間が続く。年収は390万円。

【30歳】
初めて転職活動をする。
ただ経歴書に書けるのが「担当した現場名」と「使った言語」だけで、何を判断したかが一行も書けない状態。年収は405万円。

【31歳】
書類が通らない期間が続き、いったん活動を止める。年収は410万円。

【32歳】
↓
```

### リプ2
```
【32歳（現在）】
再び転職活動を再開し、面接に来られました。年収は新卒時の約1.3倍、420万円。

面接では技術の話が普通にできる方でした。知識も足りていない印象はなかったです。ただ、10年分の「自分で決めた経験」がなかった。何を任されたかは話せても、何を選んだかが出てこないんですよね。
僕の肌感覚だと選考で止まる方の多くはスキル不足というより、この状態。今の現場で、自分の判断が入った仕事はどれくらいありますか？？
```
