# お見送り3連発→内定回答（リプ）型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「面接官10年やってますが、この質問すると大体の人は詰まります↓↓」と前置きし、面接官の質問 → お見送りの人1〜3の回答 →「内定とる人」の回答を書き出しで止めてリプへ。リプ1で内定とる人の回答を全文で見せる。

## ルール
- 絵文字は使わない。🧑‍💼😅😓😬🙂は【面接官】【お見送りの人1】【内定とる人】などの見出しに置き換える。
- 本文: 「面接官10年やってますが」＋「この質問すると大体の人は詰まります↓↓」→【面接官】「質問」→【お見送りの人1〜3】「」付きの回答 →【内定とる人】「回答の書き出し（途中で止める）。
- リプ1: 【内定とる人】「回答の全文」。軸 → 応募先との接点 → 判断の仕方、の順で3段落程度。
- 回答は具体的な社名や数字を入れず、「◯◯事業」のように読者が埋められる形にする。


### リプ1
```
🙂内定とる人
「条件も重要な判断要素の一つではありますが、
私の転職軸は“どの環境で最も成果を出せるか”という点です。

その観点で御社の◯◯事業や役割内容は、
これまでの経験を最も再現性高く活かせる環境だと感じています。

そのため、単純な条件比較だけではなく、
任される役割や成長機会を踏まえて
総合的に判断させていただきたいと考えています。」
```
