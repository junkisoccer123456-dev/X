# 企業2段階（条件付き→本命）型

- 構成（種別）: 本文 → リプ1

## 概要
本文で「〇〇な企業」を2段階に分け、下の段（条件付きで〇〇）の企業を6社ほど2列で並べ、上の段（〇〇が非常に高い）は見出しだけ出してリプに引っ張る。リプ1で上の段の企業を6社並べる。

## ルール
- 絵文字は使わない。🥈🥇は【条件付きで〇〇】【〇〇が非常に高い】などの見出しに置き換える。
- 「友達が勤務している」など、アカウントの経歴にない体験は書かない。「面接で前職として名前がよく挙がる」なども創作しない。見出しは「〇〇な企業」のように事実の分類だけにする。
- 本文: 1行目に「〇〇な企業」→【条件付き】の見出し＋6社（全角スペースで2列にそろえる）→【本命】の見出し＋「↓」。
- リプ1: 【本命】の見出し＋「・」6社。最後に、募集状況や制度は変わるので最新の求人で確認、という一言を添える。
- 企業の分類は、よく知られた事実（事業内容・自社サービスの有無など）だけで行う。確信がない企業は入れない。

## お手本

### 本文
```
友達が勤務してるリモートワーク可能な企業
🥈部署・職種次第で可能
・花王　　　　　・第一三共
・NTTドコモ　　・電通総研
・アビーム　　　・みずほ(IT)

🥇リモート比率が非常に高い↓
```
