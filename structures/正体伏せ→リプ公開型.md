# 正体伏せ→リプ公開型

- 構成（種別）: 本文 → リプ

## 概要
本文で企業の特徴（数字スペック）だけを並べて社名を伏せ、リプで社名を公開する。数値・社名はユーザーが後から埋めるテンプレートとして出力する。

## ルール
- {'本文': '「【〇〇なら】」の見出し → 「〜SaaSはここ↓↓」 → 「・〇〇【\u3000】」形式のスペック6項目 → 対象者への一言 → 「名前は…」で締める。'}
- スペックの数値は必ず【　】の空欄にする（創作禁止）。
- {'リプ': '「名前は...」→『【社名】』→【事業内容／2〜3行】→ 選び方の示唆2〜3文 → 「フォローすると、〜を発信しています」。'}

## お手本

### 本文
```
【在職中でも受けやすい】
選考が速いSaaSはここ↓↓

・面接【　】回
・オンライン完結
・結果連絡まで【　】日
・応募から内定まで最短【　】週間
・面接時間【　】分
・土日・夜の面接【　】

働きながら転職したい人向けです。名前は…
```

### リプ
```
名前は...

『【社名】』

【事業内容／2〜3行】

在職中の転職で失速する理由の大半は、日程が取れないことです。選考が速い会社を1社入れておくと、活動全体のリズムが崩れません。

フォローすると、在職中の転職の進め方を発信しています
```
