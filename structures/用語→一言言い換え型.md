# 用語→一言言い換え型

- 構成（種別）: 本文

## 概要
1投稿完結の短文。「エンジニアが〇〇で使いがちな言葉」のタイトル → 「・用語 → 一言の言い換え」を5つ → 「説明しろと言われると難しい」系の2行で締める。

## ルール
- 1行目: エンジニアが「なんとなく」で使いがちな〇〇（分野名）の言葉、など。
- 5項目: 「・用語 → 10〜15字程度の平易な言い換え」。技術的に正確にする。
- 締め2行: 知っているのと説明できるのは違う、という気づき。
- 140字を大きく超えない短さにする。

## お手本

### 本文
```
エンジニアが「なんとなく」で使いがちな言葉

・API → システム同士の窓口
・キャッシュ → よく使うデータを一時保存
・セッション → ユーザーの状態を保持
・ミドルウェア → OSとアプリの間を支える
・コンテナ → アプリの実行環境をまとめる
説明しろと言われると意外と難しい。
「知ってる」と「説明できる」の間には結構な差がある。
```
