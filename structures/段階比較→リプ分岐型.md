# 段階比較→リプ分岐型

- 構成（種別）: 本文 → リプ1 → リプ2

## 概要
本文で「面接官は〇〇ではなく〇〇を見る」と評価軸をひっくり返し、初期段階（■1〜2年目など）の行動リストを見せて「ここまではまだ〇〇」と止める。リプ1で次の段階の行動リストと、書類・面接での見られ方の差を示す。リプ2で進路ごとに何が評価されるかを分岐させて締める。

## ルール
- 本文: 1行目に"〇〇なら"のようなテーマ提示 → 「僕は『〇〇』じゃなく『〇〇』を見ます。」 → 「面接官を10年やってますが、〜は評価がほとんど変わらないです。分かれるのは...」 → 「■初期段階」＋「・」3項目 → 「ここまでは、正直まだ『〇〇』として読まれます。この先で変わってくる↓」。
- リプ1: 「■次の段階」＋「・」3項目 → 「→ ここから〜が一気に上がる。」 → 書ける人／書けない人で面接官の質問がどう変わるか → 「〜という話です。」 → 「ここから道が分かれる↓」。
- リプ2: 進路を2つ（例: 自社開発／上流に強い受託）に分け、それぞれ何が評価に乗るかを2〜3文ずつ。
- 数値の統計は創作しない。

## お手本

### 本文
```
"SESから抜けたいなら"
僕は「常駐年数」じゃなく「客先で誰と何を決めてきたか」を見ます。

面接官を10年やってますが、常駐3年の人と5年の人で、書類の評価はほとんど変わらないです。分かれるのは...

■1〜2年目
・指示された作業をこなす
・手順や進め方の改善を提案する
・作業の見積もりを自分で出す

ここまでは、正直まだ「作業者」として読まれます。この先で変わってくる↓
```

### リプ1
```
■次の段階
・客先の担当者と直接やり取りする
・仕様の確認や調整を自分で回す
・工数や納期の相談に同席する

→ ここから職務経歴書の解像度が一気に上がる。

「誰の指示で動いてたか」しか書けない人と、「誰と何を決めたか」を書ける人では、面接で聞くことが変わります。

前者は経歴の確認で終わるけど、後者は判断の理由を掘りにいく。
僕の周りの面接官を見てても、掘られてる時点でほぼ通過ラインには乗ってるという話です。

ここから道が分かれる↓
```

### リプ2
```
自社開発に行くなら、常駐中に「自分で決めた経験」をどれだけ積めたかが勝負。

SES出身で刺さるのは、技術力そのものより、複数の現場を渡ってきたキャッチアップの速さだったりします。ここを言語化できてる人はかなり強い。

上流に強い受託に行くなら、要件定義・顧客調整の経験がそのまま評価に乗る。客先とのやり取りを嫌がらずにやってきた人ほど、こっちのほうが年収は伸びやすい。
```
