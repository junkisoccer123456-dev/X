# 企業リスト（補足付き）→リプ追加型

- 構成（種別）: 本文 → リプ1 → リプ2

## 概要
本文で【見出し】と「・社名（何をしている会社か）」を5社並べ、「ほかにも⇓」でリプに引っ張る。リプ1で3社追加。リプ2で面接官の一言（優劣ではなく、語れるかどうかの差）で締める。

## ルール
- 本文: 【〇〇で働ける〇〇企業】の見出し → 「・社名（事業の補足）」×5 → 「ほかにも⇓」。
- リプ1: 「・社名（事業の補足）」×3。
- リプ2: 「面接官を10年やってますが、」から、〇〇か〇〇かで人の優劣は判断しない／ただ〇〇を自分の言葉で話せるかの差は出る／〇〇でもそこを語れる人は通る、の3文程度。
- 社名と補足は、よく知られた事実だけにする（確信がない企業は入れない）。募集状況は変わる旨を一言添える。

## お手本

### 本文
```
【客先常駐なしで働けるIT企業】

・サイボウズ（自社プロダクト開発）
・freee（自社SaaS）
・アンドパッド（建設向け自社SaaS）
・カケハシ（医療向け自社SaaS）
・アトラエ（自社サービス運営）

ほかにも⇓
```

### リプ1
```
・サイバーエージェント（自社メディア）
・DeNA（自社サービス）
・GMOインターネットグループ（自社事業）
```

### リプ2
```
面接官を10年やってますが、常駐か自社かで人の優劣を判断したことは一度もないです。ただ「何を作ってたか自分の言葉で話せるか」の差は、正直はっきり出ます。常駐でもそこを語れる人は普通に通ります。
```
