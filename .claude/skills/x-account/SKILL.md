# /x-account — アカウント情報の登録・更新

`accounts/<アカウント名>.md` にアカウント情報を保存します。保存した情報は `/x-post <アカウント名>` で投稿を書くときに、口調やルールとして使われます。

## 手順

### 1. アカウント名を決める
- `$ARGUMENTS` の最初の語をアカウント名にする（例: `/x-account tamura` なら `tamura`）。
- 空なら「どのアカウント名で登録しますか？」と聞く。ファイル名に使うので、英数字・ハイフン・アンダースコアのみにする。

### 2. 新規か更新かを確認する
- `accounts/<アカウント名>.md` が**ある**場合: 内容を短く要約して見せ、「どこを変更しますか？」と聞く。変更点だけ反映し、ほかは残す。
- **ない**場合: 新規登録として次へ進む。

### 3. 情報を集める
ユーザーがまとめて文章や資料を貼ってくれたら、そこから下の項目を読み取る。足りない項目だけを聞く（1回にまとめて聞く。1項目ずつ何度も往復しない）。

| 項目 | 必須 | 内容 |
|---|---|---|
| 立場・経歴 | ◯ | 実体験として投稿に書いてよい事実（職歴、実績、人数など） |
| 発信コンセプト | ◯ | 何を、どの立場から発信するアカウントか |
| ターゲット読者 | ◯ | 誰に向けて書くか。悩み・状況 |
| 口調 | ◯ | 一人称、です・ます／だ・である、よく使う語尾、たまに使う口語 |
| フォロー導線（CTA） | | リプの最後などで使うフォローのお願い文 |
| ルール | | 使わない言葉、必ず添える注意書き、NG表現など |
| 参考ポスト | | 過去に伸びた投稿。口調を合わせるお手本になる |
| 文字数 | | 無料（1投稿140字＝Xのカウントで280）か、Premium（長文可）か。不明ならPremiumとして扱う |

**経歴や実績は、ユーザーが教えてくれた事実だけを書く。** 推測で盛らない。わからない項目は空欄のまま「未設定」と書く。

必ず入れるルール（ユーザーが消すよう指示しない限り）:
- 数値や実績は創作しない。確認できない事実は【　】の空欄にする
- 絵文字・ハッシュタグは使わない

### 4. ファイルに保存する
`accounts/<アカウント名>.md` に次の形で書く（既存の `accounts/haru.md` が記入例）。

```markdown
# <アカウント名>

## 立場・経歴（実体験として書いてよい事実）
- ...

## 発信コンセプト
...

## ターゲット読者
- ...

## 口調
- 一人称: ...
- ...
- よく使う語尾: ... / ...
- たまに使う口語: ...

## フォロー導線（CTA）
（CTA文をコードブロックで）

## ルール
- ...

## 参考ポスト
（あれば。1本ずつコードブロックで）

## 文字数
X Premium（長文可） または 無料（280）
```

### 5. 保存を残す
クラウド環境は終了すると消えるため、保存したらコミットしてプッシュする（コミットメッセージ例: `アカウント情報を更新: tamura`）。プッシュ先は、このセッションで作業しているブランチにする。

### 6. 完了を伝える
- 登録した内容を短く要約して見せる（項目ごとに1〜2行）。
- 「未設定」の項目があれば、あとから追加できることを伝える。
- 次の操作として「`/x-post <アカウント名>` で構文を伝えると、投稿を10本作ります」と案内する。
