# 【★】X投稿生成システム

Claude Code のスラッシュコマンドで、X（旧Twitter）の投稿を作るシステムです。
APIキーは不要で、Claude Code がそのまま投稿を書きます。

## 使い方

### 1. アカウント情報を登録する

```
/x-account tamura
```

立場・経歴、読者、口調、フォロー導線（CTA）などを聞かれるので答えます。
プロフィールや過去の投稿をまとめて貼っても大丈夫です。
内容は `accounts/tamura.md` に保存されます。もう一度実行すると、内容を更新できます。

### 2. 構文を伝えて投稿を作る

```
/x-post tamura
```

構文を聞かれるので、構文名を答えるか、新しい構文の型や参考ポストを貼ります。
その構文に合う伸びそうなテーマを選び、**新しい投稿を10本**作ります。

コマンドに続けて、構文名や本数を書くこともできます。

```
/x-post tamura NG連打→OK提示型
/x-post haru 網羅リスト（↓連結）型 20本
/x-post haru 7構文
```

### 出力されるもの

- チャットに投稿の全文を表示します。
- Googleスプレッドシート `X投稿_{アカウント}_{日付}_{構文名}` を作ります（Google Drive のコネクタを接続している場合）。
  列は No / テーマ / 種別 / テキスト / date / account / structure / status / post_url / impressions / likes / bookmarks / reposts / profile_visits / note です。
- 過去に作ったシートのテーマを読み込み、同じテーマを避けます。

## 登録済みのデータ

| 場所 | 内容 |
|---|---|
| `accounts/` | アカウント情報（haru, tamura） |
| `structures/` | 構文（9種類）。`/x-post` で新しい構文を伝えると、ここに追加されて次回から名前だけで使えます |
| `.claude/skills/` | `/x-account` と `/x-post` の手順書 |
| `scripts/to_csv.py` | 投稿を管理シート形式のCSVに変換する補助スクリプト |

登録済みの構文: リスト提示→リプ回収型 / NG連打→OK提示型 / 本音提起→リプ連載解説型 / 網羅リスト（↓連結）型 / 正体伏せ→リプ公開型 / 症状連打→一言処方型 / 3段階格付け→本命公開型 / ABC3パターン / バラバラ→つながり提示型
